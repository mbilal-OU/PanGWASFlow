# PanGWASFlow

[![CI](https://github.com/mbilal-OU/PanGWASFlow/actions/workflows/ci.yml/badge.svg)](https://github.com/mbilal-OU/PanGWASFlow/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**Population-structure-aware microbial GWAS across SNPs, accessory genes, k-mers, and unitigs.**

PanGWASFlow is a reproducible Snakemake project for microbial genome-wide association studies. Its central methodological goal is to separate genotype-phenotype evidence from population-structure effects while keeping model assumptions and diagnostics visible.

## Scientific question

> Which genomic features remain associated with a phenotype after accounting for population structure and multiple testing?

## Structure-correction validation

The teaching benchmark is a deterministic synthetic stress test with **400 samples and 120 binary genomic features**. It contains one true phenotype-associated feature, 35 lineage-correlated neutral features, and 84 null features. The latent lineage label is retained only to validate the benchmark; the adjusted association model receives PCA-derived covariates, not the true lineage label.

### Population structure recovered from the feature matrix

![Synthetic population structure recovered by PCA](docs/assets/pca_structure.svg)

PC1 captures the designed lineage structure. The first two PCs explain **13.8%** and **1.8%** of feature-matrix variance, respectively.

### Naive versus structure-adjusted association

![Naive and PCA-adjusted association comparison](docs/assets/association_comparison.svg)

The deliberately confounded benchmark produces a clear contrast:

| Diagnostic | Naive scan | PCA-adjusted scan |
| --- | ---: | ---: |
| Genomic-inflation lambda | **2.06** | **1.05** |
| Significant lineage markers at BH q < 0.05 | **35 / 35** | **0 / 35** |
| Causal feature | retained | retained |
| Causal-feature q value | 1.97 × 10^-6 | 8.80 × 10^-7 |

The key result is not that PCA makes associations disappear. It is that the known lineage-driven false positives collapse while the deliberately causal feature remains strongly associated.

### QQ diagnostic

![QQ plot before and after population-structure correction](docs/assets/qq_comparison.svg)

The naive scan shows strong departure from the null expectation because lineage structure induces many correlated associations. After adjustment, lambda returns close to 1.0 and the systematic inflation is removed.

All numbers and figures above are generated from the committed validation outputs in [`examples/synthetic/results_preview`](examples/synthetic/results_preview/). The figures are reproducible SVGs generated by the package, not manually drawn illustrations.

## Published-data validation

PanGWASFlow is also validated against the public pyseer pneumococcal penicillin-resistance tutorial dataset from Figshare (`10.6084/m9.figshare.7588832`). The case study uses **603 phenotyped isolates**, starts from **10,944 accessory-gene families**, retains **6,087** features after 1% to 99% prevalence filtering, and reconstructs the published **616 × 616 Mash distance matrix** from the archived Mash sketch.

Eight classical-MDS components derived from Mash distances are included as structure covariates. Adjusted feature significance is evaluated with a logistic-regression likelihood-ratio test against one shared structure-only null model. Effect estimates and model convergence are reported separately so that separation or unstable coefficients are not mistaken for reliable biological effect sizes.

### Mash-derived population structure

![Mash-MDS population structure in the pneumococcal validation set](docs/assets/pneumococcus_mds_structure.svg)

### Naive versus Mash-MDS-adjusted calibration

![QQ comparison for the pneumococcal validation set](docs/assets/pneumococcus_qq_comparison.svg)

Genomic-inflation lambda decreases from **5.28** in the naive scan to **4.40** after Mash-MDS adjustment. The reduction demonstrates an effect of structure correction, but the remaining inflation is intentionally reported because correlated accessory-gene distributions and lineage structure remain substantial in this bacterial pangenome.

### Ranked adjusted accessory-gene associations

![Ranked accessory-gene associations in the pneumococcal validation set](docs/assets/pneumococcus_accessory_rank.svg)

The strongest stable adjusted signal is `group_4276` with LRT **p = 2.53 × 10^-22**. The identically distributed `cpsG`, `mnaA`, `tagA`, `group_3096`, `group_5738`, `group_8161`, and `group_8834` features each yield **p = 1.69 × 10^-19**. A separated feature such as `group_4417` remains in the machine-readable results but is explicitly marked as having an unstable effect estimate.

The committed [`case_studies/pneumococcus_penicillin/results_preview`](case_studies/pneumococcus_penicillin/results_preview/) and the three vector figures above are generated directly from the audited GitHub Actions output. See the full [pneumococcal case-study documentation](case_studies/pneumococcus_penicillin/README.md) for provenance, interpretation limits, and references.

## Analysis architecture

```mermaid
flowchart LR
    A[Genomic feature matrix] --> B[Sample and feature QC]
    C[Phenotype and metadata] --> B
    B --> D[Population structure]
    D --> E[PCA or distance-MDS covariates]
    B --> F[Baseline association]
    B --> G[Structure-aware association]
    E --> G
    F --> H[Multiple-testing correction]
    G --> H
    H --> I[Association and QQ diagnostics]
    H --> J[Top-hit table]
    J --> K[Biological interpretation]
```

## Quick start

PanGWASFlow requires Python 3.11 or 3.12. Install both the test and workflow extras so that the documented `snakemake` command is available in a fresh environment.

```bash
git clone https://github.com/mbilal-OU/PanGWASFlow.git
cd PanGWASFlow

python -m venv .venv
source .venv/bin/activate
pip install -e '.[test,workflow]'

snakemake --cores 1
```

Run the validated teaching benchmark:

```bash
pangwasflow demo \
  --outdir results/demo \
  --seed 42 \
  --samples 400 \
  --features 120 \
  --pcs 2
```

Prepare a real precomputed binary feature matrix:

```bash
pangwasflow prepare \
  --features core_snp_matrix.tsv \
  --metadata phenotype.tsv \
  --format matrix \
  --outdir results/prepared

pangwasflow analyze \
  --features results/prepared/features_qc.tsv \
  --metadata results/prepared/metadata_qc.tsv \
  --pcs 2 \
  --outdir results/gwas
```

When an independent sample-by-sample genomic distance matrix is available, use it for structure estimation:

```bash
pangwasflow analyze \
  --features results/prepared/features_qc.tsv \
  --metadata results/prepared/metadata_qc.tsv \
  --structure-distance genomic_distances.tsv \
  --pcs 8 \
  --outdir results/gwas
```

For a Roary/Panaroo accessory-gene table, use `--format roary` or `--format panaroo`. Pyseer/Roary-style `gene_presence_absence.Rtab` is supported with `--format rtab`. Full input specifications and QC behavior are documented in [`docs/input_formats.md`](docs/input_formats.md).

## Why structure correction is central

Microbial populations are often strongly clonal or lineage-structured. If both a genomic feature and a phenotype are lineage-correlated, an unadjusted test can identify the feature even when it is not the direct driver of the phenotype. PanGWASFlow therefore preserves baseline and structure-adjusted results side by side and reports diagnostic evidence rather than hiding the effect of correction.

## Scientific guardrails

Association is statistical evidence, not proof of causation. Population structure, phenotype quality, multiple testing, feature frequency, linkage, and model assumptions must be reported explicitly. See [`docs/scientific_guardrails.md`](docs/scientific_guardrails.md), [`docs/structure_benchmark.md`](docs/structure_benchmark.md), [`docs/input_formats.md`](docs/input_formats.md), and the [published-data case study](case_studies/pneumococcus_penicillin/README.md).
