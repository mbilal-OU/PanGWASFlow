# PanGWASFlow

**Population-structure-aware microbial GWAS across SNPs, accessory genes, k-mers, and unitigs.**

PanGWASFlow is being built as a reproducible Snakemake workflow for microbial genome-wide association analysis. The project will focus on rigorous genotype-to-phenotype association while explicitly accounting for clonal population structure and multiple testing.

> **Status:** initial project scaffold. The first validated release will use a synthetic demonstration dataset before any larger biological case study is added.
